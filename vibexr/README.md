# VibeXR Interaction Framework

Work page: [Works/VibeXRFramework.html](../Works/VibeXRFramework.html) · Live: https://rongxuanmu.github.io/vibexr/

| File | What it is |
| --- | --- |
| `codepen.html` | **Source of truth.** Exactly what goes in the CodePen HTML panel. Change log at the top, `VERSION` in `src/main.js`. |
| `index.html` | Generated by `build.py`. Don't edit it by hand. |
| `build.py` | Wraps `codepen.html` in a full HTML page for GitHub Pages and checks that the header and `VERSION` agree. |

## Testing in a headset first

`dev/codepen.html` holds work in progress and builds to https://rongxuanmu.github.io/vibexr/dev/. That page isn't linked anywhere and is marked noindex.

1. Edit `dev/codepen.html`, run `python3 vibexr/build.py`, and push to `main`. Pages deploys in about a minute.
2. Open `/vibexr/dev/?v=2` in the headset browser. Change the number each time to skip the browser cache.
3. When it's good, run `python3 vibexr/build.py --promote`. That copies dev over `codepen.html` and rebuilds both pages; then commit, push, and paste `codepen.html` into CodePen.

## Keeping CodePen and GitHub Pages in sync

**Changed on CodePen:** copy the whole HTML panel into `codepen.html`, then run `python3 vibexr/build.py` and commit.

**Changed here:** edit `codepen.html`, then run `python3 vibexr/build.py`. Paste `codepen.html` into the CodePen HTML panel (leave the CSS and JS panels empty) and commit.

For each release:
1. Add a line to the change log at the top of `codepen.html`.
2. Bump both `VibeXR Interaction Framework vX.Y.Z` in the first line and `var VERSION`; `build.py` fails if they disagree.
3. Update the version and the newest changelog entries in `Works/VibeXRFramework.html`.

## Projects built on it

The Microduck XR, Immersive Vibe, Dream Cage, Archiscape, Physics Cabinet and Robot Zoo XR builds read `codepen.html` too. After a framework change, rebuild whichever should pick it up:

```sh
python3 microduck-xr/build.py      # -> microduck-xr/index.html and codepen.html
python3 immersive-vibe/build.py    # -> local-artifacts/immersive-vibe/
python3 dream-cage/build.py        # -> dream-cage/index.html and codepen.html
python3 archiscape/build.py        # -> archiscape/index.html and codepen.html
python3 physics-cabinet/build.py   # -> physics-cabinet/index.html and codepen.html
python3 robot-zoo-xr/build.py      # -> robot-zoo-xr/index.html and codepen.html
```

Microduck's patches assert the exact framework text they replace, so a change that moves that text makes its build fail instead of shipping silently. Immersive Vibe only fails when a `// src/...` section marker disappears, so check its output after a framework change.
