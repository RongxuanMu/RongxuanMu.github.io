Geometria

AI Math Visualization Tool

Geometria is an experimental spatial mathematics tool that turns formulas, geometric concepts, and natural-language prompts into visual explorations. It focuses on making abstract mathematical structures easier to inspect through realtime rendering, parameter controls, and XR-oriented interaction thinking.

The project connects my interests in XR interaction, AI-assisted creation, and spatial design: mathematical forms are treated less like static diagrams and more like environments that can be entered, adjusted, and understood from multiple perspectives.

Demo

Interaction

  • Formula-first exploration - visualize 2D functions, 3D curves, parametric surfaces, and geometric objects.
  • AI-assisted input - translate natural-language math descriptions into renderable visual scenes.
  • Realtime parameter tuning - expose variables as sliders so mathematical change becomes visible immediately.
  • Spatial interface design - frame mathematical learning as a manipulable, immersive visual experience.
