01 · WebXR

The browser's door into headsets

WebXR is the web standard that lets a page take over a headset: open a link, tap Enter, you are in.

Sessions

VR and AR

immersive-vr for full immersion, immersive-ar for the room through passthrough.

Input

Hands to gaze

Head pose, controllers, tracked hands with 25 joints, and gaze-and-pinch on Vision Pro.

Reach

No install

Quest, PICO, Vision Pro, Galaxy XR and Android XR browsers. A URL is the whole distribution.

04 · The problems

Every prototype starts by rebuilding the same things

  • Interaction is left to you: ray, pinch, grab, poke, two-hand scale and buttons, written again for each project.
  • Inputs diverge: hands, controllers, Vision Pro's gaze pointer and a desktop mouse each behave differently.
  • VR-first habits: passthrough is an afterthought, and "VR only" makes no sense on see-through glasses.
  • Toolchains get in the way: npm, bundlers and frameworks, while AI works best with one file you can paste.
  • No desk testing: without a headset on, you can't try the interaction at all.

07 · Build on it

A world is a few lines

const Hello = {
  id: "hello",
  init(ctx) {
    const { root, THREE } = ctx;
    root.add(new THREE.HemisphereLight(0xffffff, 0x222222, 2));
    const cube = new THREE.Mesh(new THREE.BoxGeometry(0.1, 0.1, 0.1),
                              new THREE.MeshStandardMaterial());
    cube.position.set(0, 1.3, -0.5);
    root.add(cube);
    // grab near or far; two hands rotate and scale
    ctx.add(cube, { draggable: true, twoHand: true })
       // one event, whether a hand, a controller, a gaze pinch or a mouse did it
       .on("tap", () => ctx.log("tapped"));
  },
};
app.worlds.register(Hello);

09 · What we learned

Design rules that keep it working everywhere

Passthrough first

Things live in your room: a stage on the real floor or a desk at your height, measured from your head.

Diorama scale

Big worlds become tabletop or floor miniatures you can walk around, with time sped up so they don't read as slow motion.

The console rides along

Panels follow the stage they control, and each can be dragged by its own bar.

Light enough for glasses

Generated geometry, no heavy assets, so standalone headsets and puck-tethered see-through glasses keep up.
