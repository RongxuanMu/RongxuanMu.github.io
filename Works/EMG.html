Streaming Data Format (WebSocket, JSON per frame)

In Live Stream mode, this dashboard acts as a WebSocket client. Run a WebSocket server on your streaming device (e.g. ws://<device-ip>:8765) and send one JSON message per frame at ~10 Hz: 

{
  "type": "emg_frame",
  "seq": 1024,               // optional, frame counter
  "timestamp": 1752988800.123, // optional, unix seconds

  // Raw EMG: exactly 16 channels, microvolts (±70 µV display range)
  "emg": [12.4, -3.1, 45.0, ...],

  // Inferred hand pose: all values normalized 0.0 (open) … 1.0 (fully curled)
  "pose": {
    "thumb":  0.10,
    "index":  0.85,
    "middle": 0.80,
    "ring":   0.30,
    "pinky":  0.25
  },

  // Optional: estimated fingertip normal force in Newtons (0–40 N)
  "force": {
    "thumb": 2.5, "index": 12.0, "middle": 10.4, "ring": 3.1, "pinky": 2.2
  }
}
  • emg is required. If pose is omitted, pose is inferred from EMG channel groups (CH1–4 → index, CH5–8 → middle, CH9–12 → ring/pinky, CH13–16 → thumb).
  • If force is omitted, force is estimated from pose activation.
  • Messages may also be a bare 16-float array […] as shorthand for {"emg": […]}.

Minimal Python sender: 

import asyncio, json, time, websockets

async def handler(ws):
    seq = 0
    while True:
        await ws.send(json.dumps({
            "type": "emg_frame", "seq": seq, "timestamp": time.time(),
            "emg": read_emg_16ch(),          # list of 16 floats, µV
            "pose": infer_pose(),            # dict of 5 floats, 0..1
        }))
        seq += 1
        await asyncio.sleep(0.1)             # 10 Hz

asyncio.run(websockets.serve(handler, "0.0.0.0", 8765))

Note: when this page is served over HTTPS (e.g. GitHub Pages), browsers only allow ws:// connections to localhost. For a remote device, use wss:// or open this file locally.
